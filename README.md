# climate-change-temperature-anomaly-prediction Machine learning


## 📌 Project Overview
This project predicts climate temperature changes using historical climate data from 1961 to 2024. Multiple machine learning regression models were trained and compared to identify the best-performing model.

---

## 📊 Dataset
- Historical Climate Temperature Data
- Years: 1961–2024
- Countries: 200+
- Target Variable: Temperature Change (°C)

---

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib

---

## 📈 Exploratory Data Analysis
The following analyses were performed:
- Data Cleaning
- Missing Value Analysis
- Temperature Distribution
- Top 10 Countries with Highest Temperature Change
- Feature Importance
- Model Comparison

---

## 🤖 Machine Learning Models
The following regression models were trained and compared:

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting Regressor

---

## 🏆 Best Model
**Random Forest Regressor**

### Model Performance

| Metric | Value |
|--------|--------|
| MAE | 0.312 |
| RMSE | 0.429 |
| R² Score | 0.620 |

Random Forest achieved the highest R² score and was selected as the final model.
